Featured Project

Email Studio

A self-hosted developer email IDE. Write HTML/CSS in a CodeMirror editor, preview responsive layouts, convert to email-safe HTML, and send via Gmail OAuth or any SMTP provider — all from the browser.

NODE.JS EXPRESS SQLITE CODEMIRROR OAUTH 2.0
GitHub
Architecture Overview
  • Email conversion pipeline sanitizes markup, inlines CSS, converts flex layouts to tables, and hardens the output for email clients.
  • Compatibility analysis checks rendered output against Gmail, Outlook, Apple Mail, and Yahoo, with guidance for fixing issues.
  • Gmail OAuth 2.0 or SMTP credentials are supported for sending, both encrypted at rest — Gmail passwords are never requested or stored.
  • A visual editor with a property inspector and undo/redo sits alongside the code editor, backed by a sandboxed responsive preview.

Transactional Emails Convert clean HTML/CSS into email-safe markup ready to send.

A self-hosted uptime monitoring application for tracking the availability and performance of web services. Provides continuous health checks, response-time monitoring, uptime history, and incident tracking through a focused operations dashboard.

tflows.py

A lightweight Python framework for building Discord bots with script-based commands. Define bot behavior with simple scripts, use built-in functions and variables, and extend the framework with custom Python functionality while retaining the flexibility of discord.py.

PYTHON DISCORD.PY SCRIPTING OPEN SOURCE PYPI
GitHub PyPI Documentation
Architecture Overview
  • Built on discord.py with FlowBot providing the main bot interface while retaining access to Discord.py's functionality.
  • Script engine executes registered commands line by line, resolving functions and variables through the framework's FunctionRegistry.
  • Built-in functions and variables provide common Discord bot functionality without requiring every action to be implemented as Python code.
  • Extensible registry system allows developers to add their own Python functions, variables, and aliases when scripts need additional functionality.
Real Use Cases
Discord Bots Build commands and bot functionality using concise script-based definitions.
Server Automation Automate common Discord actions such as replies, reactions, message management, delays, and embeds.
Rapid Prototyping Create functional Discord commands without writing a separate Python function for every simple command.
Python Extensions Combine scripts with custom Python functions, variables, and normal discord.py features for more complex functionality.

Featured Project

tflows.py

A lightweight Python framework for building Discord bots with script-based commands. Define bot behavior with simple scripts, use built-in variables and functions, and extend the framework with your own Python functions while retaining full discord.py compatibility.

PYTHON DISCORD.PY PYPI SCRIPTING
GitHub PyPI Docs
Technical Details
Architecture Overview
  • FlowBot extends discord.py's commands.Bot, providing a familiar Discord bot foundation while adding the tflows scripting system.
  • Script Engine executes command scripts line by line, resolving functions and variables through the registry.
  • FunctionRegistry provides the extension system for built-in and custom functions, variables, and aliases.
  • FlowContext provides script functions with access to the Discord message, author, channel, guild, bot, arguments, and command context.
What It Provides
Script Commands Define Discord commands using simple script lines instead of implementing every command as Python code.
Built-in Functions Send replies, wait, react, delete messages, clear messages, create embeds, and perform other common bot actions.
Dynamic Variables Access users, servers, channels, arguments, ping, uptime, member counts, and other runtime information directly in scripts.
Python Extensions Register custom Python functions and variables when scripts need functionality beyond the built-in system.
Example
Install pip install tflows
Create a Command bot.command("ping", "reply Pong! $ping")
Extend Register custom functions and variables through the registry.
Integrate Continue using normal discord.py commands, cogs, events, listeners, and async Python code alongside tflows scripts.
