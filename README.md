# Personal Portfolio
A clean, minimal portfolio website built to showcase my work, skills, and approach to development.

---

## ✦ 🎨 Design
The design focuses on simplicity, clarity, and strong visual structure.

- 🧼 **Minimalist layout** — no unnecessary elements, content-first approach  
- ⚫⚪ **Black & white, dark by default** — dark and light themes, both strict grayscale, with a toggle to switch  
- 🧠 **Typography-driven** — monospace for headings and UI labels, clean sans-serif for body text  
- ✨ **Subtle motion** — a single lightweight fade-in on load and scroll, nothing flashy  
- 📱 **Responsive** — works across desktop and mobile, respects reduced-motion preferences  

---

## ✦ 📌 Overview
This site presents:

- 🧩 Projects and work  
- ⚙️ Technical skills  
- 📬 Contact information  

Built using plain HTML, CSS, and JavaScript for maximum performance and control.
